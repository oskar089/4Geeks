# 4Geeks - Personal Portfolio

Personal portfolio website and practice projects developed during the 4Geeks Academy Full-Stack bootcamp.

**Live demo:** [https://oskar089.github.io/4Geeks/](https://oskar089.github.io/4Geeks/)

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript

## What's Included

- **Personal portfolio** - landing page (`index.html` in the root) with projects and skills
- **Bootcamp practice projects**:
  - Calculadora edad (Age Calculator)
  - Cartas (Playing Cards)
  - Generador de excusas (Excuse Generator)
  - mis clientes (clients showcase)
  - practicas (practice exercises)
  - trabajos (course work)

## Run Locally

Open `index.html` directly in your browser, or serve the folder with any static server:

```bash
npx serve .
# or
python -m http.server
```
